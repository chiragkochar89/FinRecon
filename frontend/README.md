# FinRecon — Operations Dashboard (Frontend)

## Overview
React + TypeScript Web UI providing a modern operational dashboard for the **FinRecon Financial Reconciliation Platform**.

## Key Features
- **Environment Indicator**: Prominently displays `MODE: LOCAL DEMO` or `MODE: REAL MAINFRAME`.
- **Responsive Layout**: Sidebar navigation and modular page placeholders.
- **Enterprise Design**: Clean, professional UI tailored for financial operations.
